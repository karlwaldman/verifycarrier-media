# VerifyCarrier public media

[VerifyCarrier](https://verifycarrier.com) helps research US motor carriers with source-attributed public evidence.

[Watch or download the 1080p narrated walkthrough](https://github.com/karlwaldman/verifycarrier-media/releases/download/openai-review-walkthrough-20261003/verifycarrier-review-walkthrough.mp4). The live responses were captured October 3, 2026; saved carrier evidence is dated October 1, 2026. Captions and a transcript are included in the release.
